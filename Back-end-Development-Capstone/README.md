# Back-end-Development-Capstone
Main Django band application for the IBM Back-End Application Development Capstone.

Features: home page, Concerts model/admin, Songs page + lyrics modal, Photos page, Django auth/admin, external Songs and Pictures service integration, Docker and Kubernetes deployment.

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver 0.0.0.0:8000
```
